# 🚀 My Skill Tracker (RPG Style)

Приложение на Python для отслеживания личных целей и навыков с элементами геймификации. 
Позволяет визуализировать прогресс обучения, повышать уровни и управлять списком задач.

## ✨ Основные функции
* **Система опыта (XP):** Нажимай кнопку `+XP`, чтобы заполнять полоску прогресса.
* **Уровни (Levels):** При достижении 100% опыта уровень навыка повышается, а прогресс сбрасывается.
* **Сохранение данных:** Все навыки и их прогресс хранятся в JSON-файле и не пропадают после перезапуска.
* **Современный интерфейс:** Использование библиотеки `CustomTkinter` для темной темы и красивых виджетов.

## 🛠 Технологии
* **Python 3.x**
* **CustomTkinter** (Интерфейс)
* **JSON** (База данных)
